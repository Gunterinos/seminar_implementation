Additional Information
Algorithm steps & formulas:
The predicate is a conjunction of intervals over selected dimensions:
Φ(xi) = 1[ϕj,min ≤ xij ≤ ϕj,max for all j] Each clause is parameterized by center and width:
μj = (ϕj,max + ϕj,min) / 2
rj = (ϕj,max - ϕj,min) / 2
aj = 1 / rj Instead of a hard 0/1 rule, a soft bump function is used for optimization:
f(x) = 1 / (1 + Σj|aj(xij - μj)|b) The algorithm fits the predicate by minimizing binary cross-entropy loss, with a L1 penalty for sparsity.
L = Lbce + γ‖a‖1
Screens & views:
  • Projection View: A 2D scatter plot of the data using the selected axes. You can select a region to define a predicate.
  • Predicate Clauses: Shows the current clauses that define the predicate. Each clause corresponds to a feature and describes the range for it.
  • Clause Sliders: Lets you interactively adjust the bounds of each clause and see how the predicate changes in real time. It also shows the learned parameterf formulas and values for each clause.
Disclaimer:
  • γ (L1) parameter: Not used in the original code, but enabled here. Recommended to leave at 0 for best performance.
